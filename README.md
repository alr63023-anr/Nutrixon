# Nutrixon – Product Verification and Nutrition Platform

## About the Project

Nutrixon is a web-based product verification and nutrition platform designed to help screen food products before launch. It focuses on ingredient compliance, laboratory report review, nutrition scores, and product safety verification status.

## Problem Statement

Consumers need accessible information about food product ingredients, nutritional quality, and safety. Reviewing ingredient compliance and laboratory reports can be challenging, making it important to organize this information in an accessible platform.

## Proposed Solution

Nutrixon provides a web-based platform for reviewing food product information, ingredient compliance, laboratory reports, nutrition scores, and product safety verification status.

## Key Features

- Food product screening
- Ingredient compliance review
- Laboratory report review
- Nutrition score information
- Product safety verification status
- Web-based user interface

## Installation and Setup

### Prerequisites

- Node.js
- npm
- Git

### Steps to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/alr63023-anr/Nutrixon.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Nutrixon
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

## Production Build

To create a production build, run:

```bash
npm run build
```
